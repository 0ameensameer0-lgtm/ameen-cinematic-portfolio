# 🚀 موقع السيرة الذاتية ثلاثي الأبعاد - 3D Portfolio Website

## 📋 نظرة عامة | Overview

موقع احترافي ثلاثي الأبعاد تفاعلي لعرض السيرة الذاتية والأعمال والخدمات. تم تطويره باستخدام أحدث التقنيات الحديثة.

---

## 🎯 المميزات | Features

✨ **تصميم ثلاثي الأبعاد احترافي** - 3D Interactive Design
- عناصر ثلاثية الأبعاد متحركة باستخدام Three.js
- تأثيرات حركة سلسة ومؤثرة
- رسوميات عالية الجودة

🌍 **دعم متعدد اللغات** - Multi-language Support
- دعم العربية والإنجليزية
- تبديل سلس بين اللغات
- حفظ تفضيلات المستخدم

🎨 **مواضيع متعددة** - Multiple Themes
- الوضع الليلي (Dark Mode)
- الوضع النهاري (Light Mode)
- تأثيرات بصرية جميلة لكل نمط

📱 **تجاوب كامل** - Fully Responsive
- متوافق مع جميع أحجام الشاشات
- تصميم محمول ممتاز
- أداء سريع على جميع الأجهزة

🎬 **تأثيرات حركة متقدمة** - Advanced Animations
- تأثيرات Scroll عند التمرير
- تحريكات Hover تفاعلية
- انتقالات سلسة وجميلة

🎯 **أقسام متكاملة** - Complete Sections
- الرئيسية مع 3D
- من أنا مع المهارات
- الخدمات المتاحة
- معرض الأعمال
- الشهادات والإنجازات
- نموذج الاتصال

## 🚀 خطوات التشغيل | Installation & Running

### الخطوة 1️⃣: استخراج الملفات
```bash
# فك ضغط ملف ZIP
unzip portfolio-3d.zip
cd portfolio-3d
```

### الخطوة 2️⃣: تثبيت المكتبات
```bash
npm install
```

> ⏳ **ملاحظة**: قد تستغرق هذه الخطوة 2-5 دقائق، انتظر حتى انتهاء التثبيت

### الخطوة 3️⃣: تشغيل الموقع

#### طريقة 1: التشغيل المباشر
```bash
npm start
```

#### طريقة 2: باستخدام Node.js مباشرة
```bash
node server.js
```

### الخطوة 4️⃣: فتح الموقع
1. افتح متصفحك
2. انتقل إلى: `http://localhost:3000`
3. استمتع بالموقع! 🎉

## 🎨 تخصيص الموقع | Customization

### تعديل البيانات الشخصية

#### 1️⃣ تعديل البيانات الأساسية
في الملف `public/index.html`:
```html
<h1 class="gradient-text">أمين سمير اليوسفي</h1>
<!-- غيّر الاسم إلى اسمك -->
```

#### 2️⃣ إضافة المشاريع الخاصة بك
في الملف `src/data/portfolio.json`:
```json
{
  "id": 1,
  "title": "اسم مشروعك",
  "category": "مشاريع برمجية",
  "description": "وصف المشروع",
  "image": "رابط صورة المشروع",
  "tags": ["React", "Node.js"],
  "date": "2024"
}
```

#### 3️⃣ تحديث المهارات
في الملف `src/data/skills.json`:
```json
{
  "category": "Frontend",
  "items": ["React", "Vue.js", "Angular", ...]
}
```

#### 4️⃣ تحديث الخدمات
في الملف `src/data/services.json`:
```json
{
  "id": 1,
  "icon": "fas fa-globe",
  "title": "اسم الخدمة",
  "description": "وصف الخدمة"
}
```

#### 5️⃣ إضافة الشهادات
في الملف `src/data/certificates.json`:
```json
{
  "id": 1,
  "title": "اسم الشهادة",
  "issuer": "جهة الإصدار",
  "date": "2024",
  "credential": "رابط الشهادة",
  "image": "رابط صورة الشهادة"
}
```

### تغيير الألوان
في ملف `public/index.html` ضمن `<style>`:
```css
:root {
  --primary: #6366f1;        /* اللون الأساسي */
  --secondary: #ec4899;      /* اللون الثانوي */
  --accent: #06b6d4;         /* لون التأكيد */
  --dark-bg: #0f172a;        /* خلفية الظلام */
}
```

### تحديث معلومات الاتصال
في الملف `public/index.html` ضمن قسم Contact:
```html

<a href="https://wa.me/966XXXXXXXXX">واتساب</a>
```

## 🌐 نصائح الاستخدام | Tips & Tricks

### 1️⃣ تحسين الأداء
```bash
# قبل النشر على الإنترنت
npm run build
```

### 2️⃣ حل المشاكل الشائعة

**المشكلة**: الصفحة بيضاء
- **الحل**: تأكد من تثبيت جميع المكتبات: `npm install`

**المشكلة**: الموقع لا يفتح على localhost:3000
- **الحل**: تأكد من عدم احتلال المنفذ 3000: 
```bash
# Windows
netstat -ano | findstr :3000

# Mac/Linux
lsof -i :3000
```

**المشكلة**: لا توجد تأثيرات 3D
- **الحل**: تأكد من دعم WebGL في المتصفح

### 3️⃣ الاختبار على جهاز آخر
```bash
# اكتشف IP عنوان جهازك
# على Windows: ipconfig
# على Mac/Linux: ifconfig

# ثم افتح: http://YOUR_IP:3000
```
