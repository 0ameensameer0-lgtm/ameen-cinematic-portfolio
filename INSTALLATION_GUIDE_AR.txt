🔧 خطوات التثبيت والتشغيل
═══════════════════════════════════════════════════════════════════

📍 الخطوة الأولى: التحقق من Node.js
─────────────────────────────────────────────────────────────────

على Windows:
▸ افتح Command Prompt
▸ اكتب: node --version
▸ يجب أن ترى: v14.x.x أو أحدث

على Mac/Linux:
▸ افتح Terminal
▸ اكتب: node --version
▸ يجب أن ترى: v14.x.x أو أحدث

═══════════════════════════════════════════════════════════════════

📍 الخطوة الثانية: فك ضغط الملفات
─────────────────────────────────────────────────────────────────

1. اضغط بزر الفأرة الأيمن على ملف portfolio-3d.zip
2. اختر: "Extract All" أو "فك الضغط"
3. أختر مكاناً لحفظ الملفات

═══════════════════════════════════════════════════════════════════

📍 الخطوة الثالثة: فتح Terminal/Command Prompt
─────────────────────────────────────────────────────────────────

على Windows:
1. افتح File Explorer
2. انتقل لمجلد portfolio-3d
3. اضغط Shift + الزر الأيمن
4. اختر: "Open PowerShell window here"

على Mac:
1. افتح Finder
2. انتقل لمجلد portfolio-3d
3. اضغط Cmd + Space
4. اكتب: Terminal
5. اسحب المجلد إلى Terminal

على Linux:
1. افتح File Manager
2. انتقل لمجلد portfolio-3d
3. اضغط Ctrl + Alt + T

🆘 حل المشاكل
═══════════════════════════════════════════════════════════════════

❌ المشكلة: الصفحة بيضاء فارغة
✓ الحل:
  1. أغلق الموقع
  2. في Terminal، اكتب: npm install
  3. ثم: npm start

❌ المشكلة: Error: listen EADDRINUSE :::3000
✓ الحل: المنفذ 3000 مشغول
  - أغلق أي نوافذ متصفح تشغل الموقع
  - أو غيّر المنفذ في server.js

❌ المشكلة: Cannot find module 'express'
✓ الحل: لم يتم تثبيت المكتبات
  - في Terminal: npm install

❌ المشكلة: لا توجد تأثيرات 3D
✓ الحل: تحقق من متصفحك
  - استخدم متصفح حديث (Chrome, Firefox)
  - تأكد من دعم WebGL
